# 바이브코딩 체험부스 대기자 관리

노원수학문화축전 · 인덕과학기술고등학교 바이브코딩 체험부스에서 쓰는 병원식 대기자 관리 화면입니다.
번호표 발급, 현재 진행 번호 표시, 대기 목록, 완료 처리까지 한 페이지에서 관리합니다.

## 사용 방법

`index.html`을 브라우저로 열면 바로 동작합니다. 빌드나 서버가 필요 없습니다.

- **번호표 발급**: 이름(선택)을 입력하고 발급하면 대기 목록 맨 뒤에 추가됩니다.
- **다음 참가자 호출**: 대기 목록 맨 앞 사람을 "현재 진행중"으로 올립니다.
- **호출**: 대기 목록에서 특정 참가자를 순서와 상관없이 바로 호출합니다.
- **체험 완료 처리**: 현재 진행중인 참가자를 완료 처리하고 오늘 완료 목록에 기록합니다.
- **취소**: 대기 중인 참가자를 목록에서 제거합니다.
- **전체 초기화**: 모든 기록을 지우고 처음 상태로 되돌립니다(확인 후 진행).

데이터는 이 브라우저의 `localStorage`에 저장되어 새로고침해도 유지됩니다. 다른 기기나 탭과는
공유되지 않으므로, 행사장에서는 접수·호출을 담당하는 한 화면(예: 태블릿 1대)에서 운영하는 것을
권장합니다.

## 파일 구성

- `index.html` — 페이지 구조
- `style.css` — 디자인, 라이트/다크 테마
- `app.js` — 대기열 로직, 로컬 저장
