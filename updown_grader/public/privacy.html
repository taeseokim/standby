제1조 (총칙과 데이터 처리 구조)

「업앤다운 숫자 맞추기 게임 수행평가」(이하 "서비스")는 인덕과학기술고등학교 정보 수업에서 학생이 작성한 업앤다운 숫자 맞추기 게임 Python 프로그램을 제출받아 자동으로 실행하고 채점하는 학습지원 소프트웨어입니다. 운영자는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 이 처리방침을 공개합니다.

  • 회원가입 없음: 계정이나 비밀번호를 만들지 않습니다.
  • 최소 수집: 제출자를 확인하고 성적을 처리하는 데 꼭 필요한 정보만 받습니다. 연락처, 생년월일, 주소, 성별, 사진, 위치 정보 등은 받지 않습니다.
  • 처리 흐름: 제출 저장 → 테스트 입력으로 코드 실행 → AI 채점 → 결과 표시 → 교사 확인 순서로 처리합니다.
  • 최종 점수: AI 채점 결과는 참고 자료입니다. 최종 점수는 담당 교사가 채점 기준에 따라 확인하고 결정합니다.
  • 이용하는 외부 서비스: 웹 호스팅·코드 실행(Vercel, 서울 리전), 데이터 저장(Supabase, 서울 리전), AI 채점(OpenAI API, 미국)
  • 코드 실행 위치: 학생 코드는 외부 실행 서비스로 보내지 않고, 서비스 서버(Vercel 서울 리전) 안에서 시간·메모리 제한을 걸어 격리 실행합니다.

제7조 (정보주체의 권리와 행사 방법)

이용자(학생)와 그 법정대리인(보호자)은 언제든지 개인정보의 열람, 정정, 삭제, 처리정지와 동의 철회를 요구할 수 있습니다.

  1. 요청 방법: 제10조의 개인정보 보호책임자에게 이메일로 요청하거나 담당 교사에게 직접 말합니다. 학번, 이름, 요청 내용을 적어 주세요.
  2. 본인 확인: 학번과 이름, 수업 코드로 본인임을 확인합니다. 대리인은 위임장 등으로 권한을 확인합니다.
  3. 처리 기한: 요청을 받은 날부터 10일 이내에 조치하고 결과를 알려드립니다.
  4. 정정: 학번·이름이 잘못 입력된 경우 바로 정정합니다. 제출 코드는 평가의 공정성을 위해 제출 후 수정할 수 없으며, 필요하면 담당 교사가 재제출 여부를 판단합니다.

다만 이미 확정된 성적 기록과 같이 법령이나 학교 학업성적관리규정에 따라 보존해야 하는 정보는 삭제가 제한될 수 있으며, 이 경우 그 사유를 알려드립니다.

이 서비스는 인덕과학기술고등학교 학생의 수업용으로 운영하며, 만 14세 이상만 이용할 수 있습니다. 만 14세 미만 아동의 개인정보는 수집하지 않습니다. 만 14세 미만 학생이 이용해야 하는 경우에는 「개인정보 보호법」 제22조의2에 따라 법정대리인의 동의를 먼저 받으며, 동의 없이 수집된 사실을 알게 되면 즉시 삭제합니다.

제9조 (안전성 확보 조치)

  • 관리적 조치: 개인정보 처리자를 운영자와 담당 교사로 제한, 수업 코드로 반별 접근 구분
  • 내부 관리: 운영자가 개인정보 보호 관리 사항을 정해 연 1회 이상 점검
  • 암호화: 전송 구간은 HTTPS(TLS)로 암호화하고, 데이터베이스(Supabase)에 저장된 정보는 저장 시 암호화(AES-256)
  • 접근 통제: 교사용 페이지는 교사 비밀번호를 입력해야만 열람 가능, 데이터베이스는 행 수준 보안(RLS)으로 잠그고 서버만 아는 비밀값이 있어야 읽고 쓸 수 있게 제한(학생 화면에서는 다른 학생의 제출물을 조회할 수 없음)
  • 코드 실행 격리: 학생 코드는 실행 시간·메모리·파일 크기를 제한하고 서버 환경변수(비밀 키)를 차단한 상태로 실행
  • 비밀 정보 관리: 데이터베이스 키와 OpenAI API 키는 서버 환경 변수로만 보관하고 브라우저에 노출하지 않음
  • 접속 기록: 호스팅·데이터베이스 서비스의 접속 기록을 보관해 부정 접근 여부를 확인
  • 최소 전송: AI 채점 서비스에는 채점에 필요한 코드와 실행 결과만 보내고 학번·이름은 보내지 않음
  • 물리적 조치: 서버와 데이터는 위탁 업체의 보안 시설에서 관리
