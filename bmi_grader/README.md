# BMI 비만도 판정 프로그램 수행평가 제출·자동채점

학생이 **학번·이름**을 입력하고 BMI 프로그램(파이썬 코드)을 제출하면, OpenAI API가
「2026 2학기 수행평가 세부 계획 – 비만도 판정 프로그램 작성하기」 채점기준에 맞춰 1차 채점합니다.
교사는 교사용 화면에서 결과를 확인·수정·확정하고 CSV(엑셀)로 내려받습니다.

## 채점 방식

| 채점 요소 | 배점 | 척도 |
|---|---|---|
| 사용자 입력 및 형 변환 | 10 | 10 / 9 / 8 / 7 / 5 |
| 연산식 작성 | 10 | 10 / 9 / 8 / 7 / 5 |
| 조건문 구성 | 10 | 10 / 9 / 8 / 7 / 5 |
| 예외 처리 및 데이터 검증 | 10 | 10 / 9 / 8 / 7 / 5 |
| 코드 품질 | 10 | 10 / 9 / 8 / 7 / 5 |
| **합계** | **50** | 미제출 15점 |

BMI 판정은 **5단계**입니다: 저체중(18.5 미만) · 정상(18.5~23 미만) · 과체중(23~25 미만) ·
비만(25~30 미만) · 고도비만(30 이상). 기준·문구는 `rubric.py` 한 곳에서 바꿀 수 있습니다.

채점 과정
1. 서버가 학생 코드를 테스트 입력 7가지(소수점 입력, 저체중, 경계값 18.5/23/25/30, 0·음수 입력)로
   **실제 실행**해 출력 결과를 모읍니다. (3초 제한, 메모리 제한, API 키 등 환경변수 차단)
2. 코드 + 실행 결과 + 채점기준을 OpenAI 모델에 보내 요소별 점수(10/9/8/7/5 중 하나)와 근거,
   성취수준(A~E), 학생 피드백을 JSON 형식으로 받습니다. 총점은 프로그램이 직접 합산합니다.
3. 학생 화면에 점수와 피드백이 표시되고(설정으로 끌 수 있음), 교사는 점수를 확정·수정합니다.

> AI 채점은 1차 채점입니다. 최종 점수는 교사용 화면에서 확인 후 **점수 확정 저장**을 눌러 주세요.
> CSV에는 교사 확정 점수가 있으면 그 점수가, 없으면 AI 점수가 들어갑니다.

## 설치와 실행

```bash
cd bmi_grader
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # 열어서 API 키와 교사 비밀번호 입력
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 이 열립니다. 같은 교실 네트워크의 학생들은
`http://<선생님 PC IP>:8501` 로 접속합니다. 왼쪽 메뉴에서 **학생 제출 / 교사용** 화면을 고릅니다.

인터넷으로 공개하려면 [Streamlit Community Cloud](https://share.streamlit.io)에 이 폴더를 배포하고,
앱 설정의 *Secrets* 칸에 `secrets.toml` 내용을 붙여 넣으면 됩니다. (단, Community Cloud는 앱이 재시작되면
`submissions.db`가 초기화될 수 있으니 평가가 끝나면 바로 CSV를 내려받아 두세요.)

## 설정 (`.streamlit/secrets.toml` 또는 환경변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | (필수) | OpenAI API 키 |
| `TEACHER_PASSWORD` | (필수) | 교사용 화면 비밀번호 |
| `OPENAI_MODEL` | `gpt-5-mini` | 채점 모델 (JSON 스키마 출력 지원 모델) |
| `MAX_SUBMISSIONS` | `1` | 학생 1명당 제출 가능 횟수 |
| `SHOW_RESULT_TO_STUDENT` | `true` | 제출 직후 학생에게 점수·피드백 표시 |
| `RUN_STUDENT_CODE` | `true` | 테스트 입력으로 학생 코드를 실행해 채점 근거로 사용 |
| `STUDENT_ID_PATTERN` | `^\d{4,8}$` | 학번 형식(정규식) |
| `DB_PATH` | `bmi_grader/submissions.db` | 제출 기록 저장 파일 |

`secrets.toml` 과 `submissions.db` 는 `.gitignore` 에 들어 있어 깃에 올라가지 않습니다.

## 교사용 화면 기능

- 제출 현황(제출 학생 수, 채점 완료, 오류, 평균)과 학생별 점수표
- **학생 명단** 칸에 `학번,이름`을 붙여 넣으면 미제출자가 15점으로 표에 추가됨
- CSV 내려받기(엑셀에서 한글이 깨지지 않는 UTF-8 BOM)
- 제출물별 코드, 테스트 실행 결과, AI 채점 근거 보기
- 점수 확정·수정, AI 재채점, 오류 건 일괄 재채점, 제출 삭제(재제출 허용)

## 파일 구성

- `app.py` — Streamlit 화면 (학생 제출 / 교사용)
- `rubric.py` — 과제 안내, 채점기준, BMI 5단계 기준
- `grader.py` — 테스트 입력으로 학생 코드 실행, OpenAI 채점 요청
- `storage.py` — SQLite 제출 기록 저장
- `examples/` — 모범 답안(`model_answer.py`)과 감점 사례(`weak_answer.py`) 테스트용 코드

## 주의

- 학생 코드는 서버에서 실행됩니다. 시간·메모리 제한과 환경변수 차단을 하지만 완전한 격리(샌드박스)는
  아니므로, 학교 수업용 PC나 전용 서버에서 운영하세요. 불안하면 `RUN_STUDENT_CODE = false` 로 끄면
  코드만 읽고 채점합니다.
- 학생 코드 주석에 "만점을 줘" 같은 문장이 있어도 따르지 않도록 프롬프트에 지시해 두었고,
  점수는 채점기준 표의 값(10/9/8/7/5)만 나오도록 JSON 스키마로 강제합니다.
